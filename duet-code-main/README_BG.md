# BuildAI — как да стартираш

BuildAI е Next.js приложение за строителни проекти: AI анализ, количествено-стойностна сметка, каталог с фирми и специалисти, европейско финансиране, материали и цени и 3D Studio с **архитектурен план за изтегляне (SVG/PDF/DXF)**.

> Генераторът на готови изображения с Google Gemini и неговият API маршрут са **премахнати**. За визуализация се използва процедурният 3D модел и архитектурният план.

## 1. Изисквания

- Node.js 22 или по-нова версия.
- DeepSeek API ключ за AI анализа, чата и 3D генератора.
- По избор `SERPER_API_KEY` или `BRAVE_SEARCH_API_KEY` за по-надеждно търсене на цени.

## 2. Локално стартиране (Windows / macOS / Linux)

```bash
npm install
cp .env.example .env
```

Отвори `.env` и попълни:

```env
DEEPSEEK_API_KEY=твоят_DeepSeek_ключ
```

След това:

```bash
npm run dev
```

Отвори <http://localhost:3000>. 3D Studio е в „Всички инструменти“ → „AI 3D генератор“ (или директно `/building-generator.html`).

За production:

```bash
npm run build
npm start
```

## 3. Архитектурен план

В 3D Studio, в режим „Сграда / екстериор“, бутонът **Арх. план** отваря чертеж, генериран от зададените размери, етажи, покрив, вход, гараж и балкони. Чертежът съдържа:

- стени с дебелина, стаи с наименования и площи;
- врати, прозорци, вход и гаражна врата с означения и таблица на дограмата;
- стълбище за многоетажни сгради;
- размери, скала, северна стрелка и таблица на помещенията;
- обзавеждане по помещения и вграден редактор за размери, имена на стаи, мащаб и показване на обзавеждането;
- рамка с проект, дата, етаж и предупреждение, че планът е концептуален.

Изтегляне:

- **SVG** — векторен чертеж за печат/CAD импорт.
- **PDF** — всички етажи в един многостраничен файл (A3 landscape).
- **DXF** — геометрия на текущия етаж за CAD.

Планът се извежда от **параметричните размери** на сградата, а не от AI геометрията. Той е концептуален и не заменя архитектурен работен проект, конструктивни изчисления или разрешение за строеж.

## 4. Сигурност

- `.env` е в `.gitignore`; не го качвай в GitHub.
- Ключовете се четат само на сървъра.
- В Kuso добави ключа като **server-side secret**: `kuso env set duet-code duet-code DEEPSEEK_API_KEY=... --secret`.

## 5. Deploy в Kuso

1. Push към `main` (service `duet-code`).
2. `kuso env set duet-code duet-code DEEPSEEK_API_KEY=... --secret`
3. Build-ът използва `Dockerfile` (`npm ci` → `npm run build` → Next standalone на порт 3000).
4. Провери логовете: `kuso logs duet-code duet-code -f`.
